# Flutter SDK
Что есть:
1) Платформенный интерфейс;
2) Federated-плагин для вынесения платформенных имплементаций в разные модули;
3) Модули андроид с разными имплементациями транспортов пушей
4) Заготовка примера, который может переключать имплементации для андроида при помощи dependency_overrides
5) Пример приложения с использованием СДК

Чего не хватает: 
1) ios-имплементации
2) документации

Состав:
 - cxhub_sdk - сама библиотека
 - cxhub_platform_interface - общий платформенный интерфейс (dart)
 - cxhub_android_firebase - имплементация андроид с firebase 
 - cxhub_android_huawei - имплементация андроид с huawei
 - cxhub_android_rustore - имплементация андроид с rustore
 - cxhub_ios - имплементация ios (болванка)
 - example - пример приложения в котором при помощи dependency overrides можно менять андроид-имплементацию

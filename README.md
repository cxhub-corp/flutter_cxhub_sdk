# Flutter SDK
На текущий момент - шаблон federated-плагина, демонстрирующий возможность выбирать 
платформенную имплементацию для дроида. То есть имплементации firebase и huawei меняют только отображаемую 
строку, которая отдается платформенным кодом в единственный тестовый метод интерфейса
Чтобы из этого сделать полноценный враппер - нужно обернуть вызовы сдк сначала в платформенном виде,
потом это обернуть в вызовы канала, а их в свою очередь в дарт-интерфейс флаттер-библиотеки.

Состав:
 - cxhub_sdk - сама библиотека
 - cxhub_platform_interface - общий платформенный интерфейс (dart)
 - cxhub_android_firebase - имплементация андроид с firebase
 - cxhub_android_huawei - имплементация андроид с huawei
 - cxhub_ios - имплементация ios
 - example - пример приложения в котором при помощи dependency overrides можно менять андроид-имплементацию

# Flutter SDK
Что есть:
1) Платформенный интерфейс;
2) Federated-плагин для вынесения платформенных имплементаций в разные модули;
3) Модули андроид с разными имплементациями транспортов пушей, по сути только инициализирует нужный PlatformManager и скармливает его общему коду
4) Модуль общей логики который враппит со стороны андроида сдк и работает с каналом flutter
5) Заготовка примера, который может переключать имплементации для андроида при помощи dependency_overrides

Чего еще не хватает:
1) ios-имплементации
2) функионального примера
3) проброса пушей и возможно обработчика ошибок на уровень флаттера (просто потому что они есть в оригинале)

Состав:
 - cxhub_sdk - сама библиотека
 - cxhub_platform_interface - общий платформенный интерфейс (dart)
 - cxhub_android_common - андроид-модуль общей части для всех трех способов доставки пушей
 - cxhub_android_firebase - имплементация андроид с firebase 
 - cxhub_android_huawei - имплементация андроид с huawei
 - cxhub_android_rustore - имплементация андроид с rustore
 - cxhub_ios - имплементация ios
 - example - пример приложения в котором при помощи dependency overrides можно менять андроид-имплементацию

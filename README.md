# Flutter SDK

## Назначение
Flutter CxHub SDK предназначено для интеграции пуш-уведомлений, рассылаемых с CxHub в ваше приложение.

## Состав:
 - [cxhub_sdk](./cxhub_sdk/) - сама библиотека
 - [cxhub_platform_interface](./cxhub_platform_interface/) - общий платформенный интерфейс 
 - [cxhub_android_firebase](./cxhub_android_firebase/) - имплементация для андроид с firebase 
 - [cxhub_android_huawei](./cxhub_android_huawei/) - имплементация для андроид с huawei
 - [cxhub_android_rustore](./cxhub_android_rustore/) - имплементация для андроид с rustore
 - [cxhub_ios](./cxhub_ios/) - имплементация для iOS 
 - [example](./example/) - пример приложения 
 - [cxhub_sdk/example](./cxhub_sdk/example/) - пример приложения для локальной сборки

## Руководство по внедрению
